14–19. الأنماط الخمسة لتفكير العقلية الابتكارية: الفضول، تحدّي الافتراضات، التجريب، التعلّم من الفشل، التكيّف (بقصة موثّقة لكل نمط)
20. نشاط تطبيقي — شخّص عقليتك
21. الخلاصة + بطاقة التزام + جسر لليوم الثاني

## ✍️ إضافة الأيام 2–6 لاحقاً

كل يوم يُبنى بنفس نمط اليوم الأول:
1. أضِف شرائحه في `COURSE.slides` (في كلا ملفَي trainee) بعد آخر شريحة حالية، وحدّث `isLast` ليبقى على آخر شريحة فعلياً.
2. حدّث `status` لليوم المقابل في `COURSE.days` من `'soon'` إلى `'active'`.
3. أضِف سكريبت المدرّب المقابل في `TRAINER.scripts` داخل `trainer.html`.
4. وسّع `AI_SYSTEM_PROMPT` ليشمل تفاصيل اليوم الجديد.
